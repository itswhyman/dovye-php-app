# DOVYE Studio — Master PHP Web App

Modern, yüksek performanslı ve güvenli PHP 8.3 & MariaDB web altyapısı.

## Özellikler
- **Tasarım:** Dark-mode, glassmorphic UI, responsive grid, mikro-etkileşimler.
- **Güvenlik:** PDO Prepared Statements, CSRF Token koruması, Honeypot bot tuzağı, Rate-limiting, XSS Kaçış koruması, Security Headers.
- **Yönetim Paneli:** Müşteri adayları takibi, tek tıkla durum güncelleme, canlı istatistik grafikleri, CSV dışa aktarma.
- **Docker Uyumlu:** Coolify v4 & Traefik için hazır Dockerfile.
